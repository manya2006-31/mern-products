# MERN Products - CRUD Operations

A product management app that performs Create, Read, Update and Delete
operations using HTML, CSS, JavaScript (fetch) and a Node.js / Express REST API.

## How to run
1. npm install
2. npm start
3. Open http://localhost:3000

## API Endpoints
- GET /api/products
- POST /api/products
- PUT /api/products/:id
- DELETE /api/products/:id
